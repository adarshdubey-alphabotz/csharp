# Feature Matrix: Pokémon GO Android Application

This matrix contrasts the observed reverse-engineered features from `test.apk` against the verified implementation status and automated unit test coverage in the independent clean-room project.

| Feature | Classification | Component / Class Location | Verification & Test Coverage |
|---|---|---|---|
| **Auto-catch** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`service/PokemonGoPlusService.kt` | Evaluates wild spawns within 80m range, selects preferred ball with fallback, executes capture logic, and emits `AutoCatchEvent`. Verified in `AutomationEngineTest.kt`. |
| **Auto-spin PokéStops** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`service/PokemonGoPlusService.kt` | Filters PokéStops within 40m range, checks cooldown status, awards items and XP, and emits `AutoSpinEvent`. Verified in `AutomationEngineTest.kt`. |
| **Speed-up controls** | IMPLEMENTED AND TESTED | `data/movement/MovementModels.kt`<br>`ui/screens/MapScreen.kt` | 4 discrete speed presets: Walk (9.3 km/h), Run (18.5 km/h), Cycle (30.0 km/h), Drive (60.0 km/h) with m/s conversion and toolbar selector. Verified in `MovementControllerTest.kt`. |
| **Key activation & licensing UI** | IMPLEMENTED AND TESTED | `data/activation/ActivationManager.kt`<br>`ui/screens/SettingsScreen.kt` | Interactive activation dialog, license validation for dev test keys (`DEV-PRO-2026`, `TRIAL-7DAYS`, `LIFETIME-PRO`, `PRO-XXXX-XXXX`), and tier badges. Verified in `ActivationSystemTest.kt`. |
| **Activation state persistence** | IMPLEMENTED AND TESTED | `data/activation/ActivationManager.kt` | Persists license key, tier, and expiration timestamp in `SharedPreferences` (`cleanroom_activation_prefs`). Expiration and remaining days verified in `ActivationSystemTest.kt`. |
| **Feature access & settings** | IMPLEMENTED AND TESTED | `data/activation/ActivationManager.kt`<br>`ui/screens/SettingsScreen.kt` | Decoupled feature gating via `isFeatureUnlocked(ProFeature)` with interactive UI toggles and Pro lock protection. Tested in `ActivationSystemTest.kt`. |
| **Joystick** | IMPLEMENTED AND TESTED | `data/movement/MovementController.kt`<br>`ui/screens/MapScreen.kt` | Floating on-screen circular draggable virtual thumbstick with continuous movement coroutine and velocity vector scaling. Tested in `MovementControllerTest.kt`. |
| **Map and movement controls** | IMPLEMENTED AND TESTED | `data/movement/MovementController.kt`<br>`ui/screens/MapScreen.kt` | Interactive map canvas, GPS updates, directional navigation buttons, and radar pulse. Verified in `MovementControllerTest.kt`. |
| **Tap to Walk** | IMPLEMENTED AND TESTED | `data/movement/MovementController.kt`<br>`ui/screens/MapScreen.kt` | Single-tap sets destination waypoint with visible line and gold marker, stepping player along trajectory at designated speed. Tested in `MovementControllerTest.kt`. |
| **Double Tap to Teleport** | IMPLEMENTED AND TESTED | `data/movement/MovementController.kt`<br>`ui/screens/MapScreen.kt` | Double-tap instant relocation with realistic softban cooldown curve (up to 7200s cap) and active cooldown banner. Tested in `MovementControllerTest.kt`. |
| **Enhanced Throw** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`ui/screens/EncounterScreen.kt` | Overrides throw evaluation to guaranteed 100% EXCELLENT score (1.7x multiplier) and Curveball bonus (1.7x multiplier). Verified in `AutomationEngineTest.kt`. |
| **Auto Feed** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`service/PokemonGoPlusService.kt` | Monitors buddy hunger and automatically feeds available berries (Razz, Nanab, Pinap) when hunger falls below 30%. Verified in `AutomationEngineTest.kt`. |
| **Inventory IV** | IMPLEMENTED AND TESTED | `ui/screens/PokemonBoxScreen.kt` | Displays color-coded IV percentage badges (100% Gold, 82%+ Green, 67%+ Blue, Gray) on every Pokémon card in the collection box. |
| **Encounter IV** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`ui/screens/EncounterScreen.kt` | Real-time encounter HUD showing exact IV%, appraisal stars (0-4★), ATK/DEF/STA stats, and exact calculated CP. Verified in `AutomationEngineTest.kt`. |
| **Caught Preview** | IMPLEMENTED AND TESTED | `data/automation/AutomationEngine.kt`<br>`ui/screens/EncounterScreen.kt` | Instant catch probability calculation banner displayed upon ball throw before shake sequence completes. Verified in `AutomationEngineTest.kt`. |
| **Pokémon collection, encounters, eggs, buddies, gyms, inventory** | IMPLEMENTED AND TESTED | Core repository and UI screens | 151 Gen 1 Pokédex, real throw physics, gym combat, egg hatching, buddy walking, item bag, streaks. Verified in `PokemonGoMechanicsTest.kt`. |
